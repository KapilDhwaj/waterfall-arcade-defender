# Waterfall Arcade Defender

A 2D arcade defender game built using Godot 4.

🎮 **[Play the Web Demo on itch.io](https://kapildhwaj.itch.io/watterfallrunner)**

---

## 🕹️ Controls
- **Desktop:** `Left Arrow` / `Right Arrow` or `A` / `D` to dodge falling enemies.
- **Mobile:** Tap the left or right side of the screen.

## 🛠️ Built With
- **Engine:** Godot Engine 4.x
- **Language:** GDScript
- **Target Platform:** Web (HTML5 / WebAssembly)
